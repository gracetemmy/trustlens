The AI proposes. The contract disposes.

A risk model should never hold the keys. TrustLens separates what is estimated from what is enforced, and the enforcement layer can always overrule the estimate.

TrustLensVault.sol — the model never gets the last word
function borrow(RiskAttestation calldata a, bytes calldata sig, uint256 amount) external {
    require(a.subject == msg.sender,          "wrong subject");
    require(block.timestamp <= a.validUntil, "expired");
    require(!usedNonce[a.nonce],              "replay");

    address signer = _recover(a, sig);
    require(teeMachineRegistry.isRegistered(extensionId, signer), "not a TEE signer");

    // Deterministic guardrail — independent of anything the model said.
    uint16 ltv = a.maxLtvBps > MAX_ALLOWED_LTV_BPS ? MAX_ALLOWED_LTV_BPS : a.maxLtvBps;
    (uint256 price, ) = ftsoV2.getFeedByIdInWei(XRP_USD);
    require(_collateralValue(msg.sender, price) * ltv / 10000 >= amount, "undercollateralised");

    _disburse(msg.sender, amount);
}
The test that matters

Assume the model is completely compromised and returns PRIME for every request. What is the worst outcome? Borrowers reach the hard cap in MAX_ALLOWED_LTV_BPS — a level the protocol already considers survivable — and every position is still checked against a live FTSOv2 price the model cannot influence. A broken model costs efficiency, not solvency.

What we don't claim

Calibration, not clairvoyance.

We don't claim to predict markets. The model answers one narrow, testable question, and we report how often it's right rather than an unfalsifiable confidence number.

Real labels

Forward-looking liquidation-breach outcomes derived from historical XRP prices. No synthetic data.

Walk-forward

Time-series validation, never random splits. Brier score and a reliability curve against a Monte-Carlo baseline.

Deterministic

Inference is bit-identical in the enclave, which is what makes the pinned image hash meaningful.

Stated limits

One asset, one 7-day horizon, not audited, not investment advice. The contract floor is what protects lenders.
